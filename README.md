# 📱 StudyHub - אפליקציית Expo

אפליקציית ניהול סטודנטים מלאה עם Expo ו-React Native

## ✨ תכונות

- 🎓 **מסך כניסה מעוצב** עם אנימציות
- 📊 **סקירה כללית** עם סטטיסטיקות
- 📝 **ניהול ציונים** - הוסף ציונים וצפה בממוצע
- ✅ **ניהול מטלות** - עדיפויות וזמנים
- 📅 **לוח זמנים** - שיבוץ שבועי
- 🧠 **נושאי למידה** - סמן נושאים שיודעת
- 💾 **אחסון מקומי** - כל הנתונים שלך בטוח

## 📦 דרישות

- Node.js 16+
- npm או yarn
- Expo CLI

## 🚀 התקנה והפעלה

### 1. התקנת Expo CLI
```bash
npm install -g expo-cli
```

### 2. יצירת תיקייה חדשה
```bash
mkdir StudyHub
cd StudyHub
```

### 3. העתקת הקבצים
העתק את כל הקבצים (App.tsx, package.json, app.json) לתיקייה

### 4. התקנת תלויות
```bash
npm install
# או
yarn install
```

### 5. הפעלת האפליקציה

#### לדסקטופ (Web)
```bash
expo start --web
```

#### ל-iOS
```bash
expo start --ios
```

#### ל-Android
```bash
expo start --android
```

#### ל-Expo Go (פשוט ביותר!)
```bash
expo start
```
סרוק את ה-QR code עם האפליקציה **Expo Go** בטלפון שלך

## 🎯 איך להשתמש

### מסך הכניסה
1. בחר סוג משתמש (סטודנט/מרצה)
2. הזן דוא"ל וסיסמה (כל ערך יעבוד בדמו)
3. לחץ על "התחברות"

### ניהול ציונים
1. לך לכרטיסייה "ציונים"
2. לחץ על + כדי להוסיף ציון
3. מלא את הפרטים (קורס, ציון, סוג)
4. הממוצע יחושב אוטומטית

### ניהול מטלות
1. לך לכרטיסייה "מטלות"
2. לחץ על + כדי להוסיף מטלה
3. הוסף שם, קורס, תאריך, עדיפות
4. סמן כהושלמה כשתסיים

### לוח הזמנים
1. לך לכרטיסייה "לוח זמנים"
2. בחר יום, שעה ופעילות
3. שיבוץ יופיע בכרטיס היום

### נושאי למידה
1. לך לכרטיסייה "למידה"
2. הוסף נושא עם שם הקורס
3. סמן "יודע" או "צריך חזרה"

## 🔐 אבטחה

- כל הנתונים מאוחסנים מקומית בטלפון שלך
- אין שידור לשרת (בדמו)
- AsyncStorage ממוצפן

## 🎨 עיצוב

- צבעים אותנטיים: סגול וורוד/טורקיז
- אנימציות חלקות
- ממשק ידידותי למשתמש
- תמיכה בערבית (RTL)

## 📞 תמיכה

אם יש בעיות:
1. וודא שהתקנת את כל התלויות (`npm install`)
2. נסה `expo start --web` כדי להתחיל
3. בדוק שה-Node.js מעודכן

## 📱 בדיקה בטלפון

1. הורד את **Expo Go** מחנות האפליקציות
2. הרץ `expo start`
3. סרוק את ה-QR code עם Expo Go
4. האפליקציה תופיע בטלפון שלך!

## 🚀 פרסום

כשתרצה להוציא לייצור:
